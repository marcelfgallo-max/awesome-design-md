# MG Works Design System

Sistema visual e digital para uso geral da MG Works, com padrões que também podem ser aplicados a produtos como Northbound Financial Intelligence.

Esta entrega parte da identidade MG Works aprovada como provisória, dos materiais versionados em `branding/mgworks-v1/` e `branding/northbound-v2/`, e da referência visual DEVENZ STUDIO no Behance. Ela amplia o uso digital e editorial sem editar ou substituir os logotipos existentes.

## Arquivos

- `index.html`, catálogo visual local com exemplos e navegação por seção.
- `mobile-preview.svg`, simulação estática da composição mobile em 390 px.
- `mobile-preview.png`, imagem da composição mobile para visualização em dispositivos que não exibem SVG.
- `GUIDE.md`, princípios, identidade, expressão, aplicações e governança.
- `TOKENS.md`, inventário de tokens e critérios de uso.
- `tokens.json`, fonte estruturada dos valores.
- `tokens.css`, variáveis CSS prontas para interfaces web.
- `components.css`, estilos reutilizáveis para controles e padrões de interface.
- `COMPONENTS.md`, anatomia, variantes, estados e acessibilidade dos padrões de interface.
- `IMPLEMENTATION.md`, instruções para adotar o sistema e exemplo de marcação.

## Como abrir

Abra `index.html` em um navegador. A página usa somente arquivos locais do repositório. As fontes e assinaturas de marca são carregadas das pastas existentes.

## Estado

Versão inicial para avaliação. Os valores da identidade existentes foram mantidos. A barra cromática laranja para azul claro é uma extensão expressiva inspirada na referência, com uso restrito a linhas, sinalização e peças de comunicação. Ela não altera os logotipos aprovados.

O nome MG Works continua provisório conforme `branding/POSITIONING.md`. Este sistema não confirma disponibilidade de marca, não altera o status de publicações e não autoriza uso comercial de ativos de terceiros.
